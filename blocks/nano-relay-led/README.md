# Relay and LED on a Nano

D2 turns the relay module on and off once a second. COM and NO switch the LED from the 5 V rail through 220 ohm.

The module lies beside the breadboard, as a real one does: jumpers run from the breadboard to its header pins, which point up, and to its screw terminal.

Check it with `orbe check scene.jsonc` and run its tests with `orbe test`.
